# 🚀 TaskFlow

TaskFlow is a premium SaaS productivity platform built with React + Vite, designed to deliver a modern enterprise-grade workspace experience. The application combines intelligent task management, habit tracking, productivity analytics, focus sessions, and workspace organization into a sleek and responsive dashboard built for modern workflows.

---

## ✨ Features

- 🔐 Authentication System
  - Email login/signup
  - Google authentication
  - Guest mode access
  - Protected routes
  - Multi-user workspace isolation

- ✅ Task Management
  - Create, update, complete, and delete tasks
  - Priority management
  - Productivity tracking
  - Task analytics

- 📊 Analytics Dashboard
  - Productivity overview
  - Weekly insights
  - Focus statistics
  - Progress tracking
  - Interactive visual analytics

- 🎯 Goals & Habits
  - Goal progress management
  - Habit tracking system
  - Streak analytics
  - Consistency insights

- ⏳ Focus Timer
  - Pomodoro productivity timer
  - Session tracking
  - Focus statistics
  - Productivity enhancement tools

- 📄 PDF Productivity Reports
  - Professional report generation
  - Analytics summaries
  - Task breakdowns
  - Exportable productivity reports

- 🎨 Premium UI/UX
  - Modern SaaS-inspired interface
  - Responsive mobile-first design
  - Dark & Light themes
  - Smooth animations and transitions
  - Enterprise-grade dashboard aesthetics
